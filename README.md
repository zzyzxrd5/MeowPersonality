# 小猫人格研究所 · 静态版本

所有资源均为静态文件，无后端、数据库或站内支付。测试内容使用 AES-GCM 加密，访问口令只用于本机浏览器解密，不传往服务器。

支持根域名与 GitHub Pages 项目子路径，默认入口 index.html。分享文案包含当前站点链接，图片不含网址。

浏览器需要 HTTPS（本地 localhost 除外）及 Web Crypto。请勿在此仓库公开访问口令或未加密题库。

本项目用于技术演示与访问测试；GitHub Pages 的商业使用限制见 https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits 。正式商业托管须选择允许该用途的平台。
